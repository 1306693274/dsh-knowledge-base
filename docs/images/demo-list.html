发布流程

1. 改动先落分支，跑一遍固定用例表（全绿才继续）。
2. 生成对外副本：走白名单脚本，命中私有串就整体失败。
3. 打 tag → 写 Release → 推送；失败先查现场，不盲目重试。
4. 回滚点保留在 backups/，5 分钟内能退回。
